# Data Analysis: Learning & Teaching

This repository supports learning and teaching introductory data analysis in psychology.

It contains:

- an abbreviated syllabus;
- weekly Study Guides;
- assignment pages; and
- course resources.

The Study Guides are intended to be developed from the lecture notes, tutorials, exercises, and readings supplied for each subject.

## Quarto website

Render locally with:

```bash
quarto render
```

Preview locally with:

```bash
quarto preview
```

The site is configured to render to the `docs/` directory for GitHub Pages.
